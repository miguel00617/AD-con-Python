# AD-con-Python
Un Análisis descriptivo y comparativo

Este proyecto de análisis de datos, busca explicar y describir como afectó el Crimen en dos años, en 2019 y el 2023, mostrando las principales diferencias, similitudes y progresos teniendo una pandemia de por medio, y considerandola como factor.

Primero ejecutamos una serie de limpieza de datos, simplificación y transformación, porque encontramos columnas con datos poco claros o inadecuados para análisis y visualización. Teniendo presente que los data sets presentan a los delitos llevados a cabo en CABA. nos encontramos con errores como barrios del conurbano, datos que pueden estar fallidos, o no vienen al caso. Otro error común fueron los barrios o días mal registrados o duplicados.

Luego realizamos un análisis de cada columna reelevante, y agrupando las columnas en tres campos principales: Tiempo, Geografía y Categoría. Se van viendo las diferencias en cada campo y que aspecto y característica fue mas afectada, tambien podemos ver cuáles son las características mas concurrentes.

Luego realizamos una serie de visualizaciones con gráficos.
